💻 PC einrichten

Python installieren, dann buddy.py herunterladen und im selben Ordner ausführen:

pip install pyserial
python buddy.py install

Das trägt Hooks in Claude Code ein. Jede neue Sitzung meldet dem Buddy dann, was sie gerade tut – per USB oder WLAN (python buddy.py wifi bzw. am Gerät beide Tasten 2 s halten). Testen: python buddy.py demo.
