Claude-Buddy

Ein kleiner Begleiter, der zeigt, was Claude Code gerade macht – auf dem LILYGO T-Display-S3, dem SenseCAP Watcher oder dem Waveshare AMOLED 1.75C. · Build 14 · Inoffizielles Bastelprojekt, kein Produkt von Anthropic.

💻 Windows-Programm

Ein Installer, der alles erledigt: Buddy anstecken – der Assistent bespielt ihn bei Bedarf, bringt ihn ins WLAN, koppelt ihn, lädt die Spracherkennung und verbindet Claude Code. Danach sitzt er als Symbol neben der Uhr und aktualisiert sich und die Buddys von selbst.

⬇ ClaudeBuddySetup.exe laden

  1. Installer starten (ohne Administratorrechte). Warnt Windows („Der Computer wurde durch Windows geschützt“): Weitere Informationen → Trotzdem ausführen.
  2. Buddy per USB anstecken und den Einrichtungsassistenten durchklicken.
  3. Claude Code neu starten – ab dann meldet jede Sitzung dem Buddy, was sie tut.

🐧 Linux-Programm

Dasselbe Programm für Linux als AppImage – eine Datei, keine Installation. Stimmen: Kerstin und Thorsten (Piper, offline).

⬇ PC / Laptop (x86_64) ⬇ Raspberry Pi (ARM64)

  1. Ausführbar machen und starten: chmod +x ClaudeBuddy-*.AppImage, dann doppelklicken.
  2. Zugriff auf USB einmalig erlauben: sudo usermod -aG dialout $USER, danach ab- und wieder anmelden.
  3. Für Sprechen per Knopf: xdotool (X11) bzw. wtype (Wayland) installieren. GNOME zeigt das Symbol neben der Uhr mit der Erweiterung „AppIndicator“.

Ganz ohne Programm geht auch das PC-Skript: buddy.py mit pip install pyserial pillow und python3 buddy.py install.
